# Connect Four for Android

A two-player pass-and-play Connect Four game built with Expo and React Native.
The rules live in `src/game`, and the board and animations live in `src/screens`.

## Run on Android with Expo Go

Use Node.js 22.13.x or newer, then run:

```powershell
npm.cmd install
npm.cmd start
```

Open Expo Go on the Android phone and scan the QR code. Keep the phone and
computer connected to the same Wi-Fi while developing.

## Checks

```powershell
npm.cmd test
npm.cmd run typecheck
```
